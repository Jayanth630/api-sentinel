Core Capabilities

Engineered for Total API Reliability

Five dedicated monitoring layers working together to keep your REST endpoints responsive, resilient, and fully observable.

Real-Time API Health Monitoring

Dispatches actual network requests on configurable schedules (10s to 1h) with sub-millisecond precision. Supports full HTTP method parity (GET, POST, PUT, DELETE, PATCH, HEAD), custom headers, and bearer tokens.

HTTP Methods Custom Headers Parallel Sweeps

Network Error & Connection Detection

Deep network failure classification isolates DNS lookup drops (NXDOMAIN), SSL/TLS certificate verification failures, TCP connection refusals, and socket timeouts before HTTP status codes are even returned.

DNS Dropouts SSL Verification Socket Timeouts

HTTP 5xx & Status Code Intelligence

Instantly catches server crashes and gateway faults (500, 502, 503, 504). Validates against expected status codes, categorizes status distributions (2xx/3xx/4xx/5xx), and extracts diagnostic response headers.

5xx Catching Distribution Charts Diagnostic Logs

High-Resolution Latency Analytics

Measures response times with Python's microsecond time.perf_counter(). Computes Min, Max, Average, and true P95 percentiles over 1h, 24h, 7d, and 30d timeframes with interactive Chart.js graphs.

P95 Percentiles Timeline Graphs Performance Benchmarks

Automated Incident Management

Instant incident creation upon consecutive probe failures with root-cause logging. Features second-precision outage duration tracking, automatic resolution on service recovery, and CSV post-mortem exports.

Auto-Resolution Second Precision CSV Audit Exports
